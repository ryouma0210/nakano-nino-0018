# 寸止め耐久チャレンジのデフォルト画像

現在アプリで使う画像は、以下の3ファイルです。
差し替える場合は、同じファイル名・形式でこのフォルダーへ上書きしてください。

| ファイル | 表示する状態 |
| --- | --- |
| `tyarennzi-1.png` | 開始前・再開後・プレイ中 |
| `tyarennzi-2.png` | 一時停止中（30秒の休憩を含む） |
| `tyarennzi-3.jpg` | 終了結果 |

- 通常・一時停止用はPNG形式、終了用はJPEG形式を使用します。
- 比率が違う画像も全体が収まるように表示し、切り取りません。
- ファイル名を変更・削除するとビルドできなくなるため、同名で差し替えてください。
- アプリに同梱する画像なので、差し替え後はアプリの再ビルド・再配布が必要です。
- 利用者が「画像を設定」で格納画像を選んでいる状態では、その画像を優先します。「デフォルト画像」を選ぶと、このフォルダーの画像へ戻ります。

対応する静的な画像参照は `src/features/rhythm/defaultImages.ts` で管理しています。
