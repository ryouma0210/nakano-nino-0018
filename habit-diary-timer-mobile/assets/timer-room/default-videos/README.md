# 監禁部屋のデフォルト動画

再生と切り替えを確認するための、色・番号・動く目印だけのテスト動画3本です。

| ファイル名 | 表示 |
| --- | --- |
| `test-1.mp4` | 青・TEST 1 |
| `test-2.mp4` | 緑・TEST 2 |
| `test-3.mp4` | 紫・TEST 3 |

各動画は8秒、640×360、24fps、H.264形式で、音声はありません。
`src/features/timerRoom/TimerRoomMedia.tsx` から、この3本を静的に参照しています。

開始前は1番を表示します。実行中は自動再生・ループし、1分ごとに
直前と異なる動画へランダムで切り替わります。「前へ」「次へ」での手動切替も可能です。
手動選択は次の自動切替まで有効です。格納ファイルの選択は手動切替のままです。
読み込みに失敗した場合は廊下の画像を表示し、再試行できます。

同梱素材の登録・差し替え後は、開発環境で再読み込みしてください。
配布済みアプリへ反映する場合は、再ビルド・再配布が必要です。
