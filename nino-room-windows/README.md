# Nino Room Windows

Android版から切り離した、ElectronベースのWindows専用アプリです。

メッセージ・日付処理・契約ルールはルートの `shared/` を参照します。画像・動画・音声はモバイル版の `assets/` を原本とし、起動・ビルド前に自動同期します。同じ内容を両方で修正する必要はありません。

## 開発起動

```powershell
npm install
npm run dev
```

## Windows配布物の作成

```powershell
npm run build:windows
```

セットアップ用のインストーラー（EXE）を生成します。通常時のウィンドウ位置・サイズ、最大化状態、全画面表示、表示倍率はWindowsのユーザーデータ領域へ保存します。

広いウィンドウでは左側に8項目のナビゲーションを表示し、会話のある画面は会話・画像と操作欄を横に並べます。タスクも2列で表示します。幅を小さくすると縦並びと下部ナビゲーションへ切り替わります。館の外ではナビゲーションを表示しません。

## 操作

- 「アプリ設定」→「画面表示」から全画面表示と表示倍率を変更できます。開始画面から開くアプリ設定にも表示します。
- 全画面表示は次回起動時にも引き継ぎます。通常表示へ戻すと、全画面にする前のウィンドウサイズに戻ります。
- `F11`: 全画面の切り替え
- `Ctrl + +`: 拡大
- `Ctrl + -`: 縮小
- `Ctrl + 0`: 100%へ戻す
- 表示倍率: 75%〜200%
- ショートカットはアプリにフォーカスがあるときだけ反応します。
